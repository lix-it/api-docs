# LinkedIn Messages API

Retrieve and send LinkedIn messages for a given conversation. `viewer_id` is required for both endpoints.

## Get Messages

Retrieve the messages in a LinkedIn conversation.

<Note variant="purple">
Uses 1 Standard Credit.
</Note>

### HTTP Request

`GET https://api.lix-it.com/v1/li/messages`

### URL Parameters

#### Required Parameters

Parameter | Description
--------- | -----------
viewer_id | The Lix viewer id of the account you would like to view this conversation as.
conversation_id **or** conversation_urn | The Lix conversation id (e.g. `2-OGFlYjMwMDItZmZhYS00YmI0LTgxNDEtN2JiNTQ1MzIxODFkXzEwMA==`) or the full LinkedIn conversation URN. You must provide exactly one of these two parameters.

#### Optional Parameters

Parameter | Default | Description
--------- | ------- | -----------
sequence_id | | A Lix sequence id returned from a previous request. Pass it back to load the next page of messages.
delivered_at | | A timestamp anchor for pagination around a specific message.
count_before | 0 | Number of messages to load before the anchor.
count_after | 0 | Number of messages to load after the anchor.

<CodeGroup title="Get Messages" tag="GET" label="/v1/li/messages">
```bash {{ title: 'Shell' }}
curl "https://api.lix-it.com/v1/li/messages?viewer_id=YOUR_VIEWER_ID&conversation_id=YOUR_CONVERSATION_ID" \
  -H "Authorization: lixApiKey"
```

```python {{ title: 'Python' }}
import requests

url = "https://api.lix-it.com/v1/li/messages?viewer_id=YOUR_VIEWER_ID&conversation_id=YOUR_CONVERSATION_ID"

headers = {
    'Authorization': 'lixApiKey'
}

response = requests.get(url, headers=headers)
print(response.json())
```

```go {{ title: 'Go' }}
package main

import (
    "fmt"
    "io/ioutil"
    "net/http"
    "log"
)

func main() {
    req, err := http.NewRequest("GET", "https://api.lix-it.com/v1/li/messages?viewer_id=YOUR_VIEWER_ID&conversation_id=YOUR_CONVERSATION_ID", nil)
    if err != nil {
        log.Fatal(err)
    }

    req.Header.Set("Authorization", "lixApiKey")

    client := &http.Client{}
    resp, err := client.Do(req)
    if err != nil {
        log.Fatal(err)
    }
    defer resp.Body.Close()

    body, err := ioutil.ReadAll(resp.Body)
    if err != nil {
        log.Fatal(err)
    }

    fmt.Println(string(body))
}
```

```javascript {{ title: 'Node.js' }}
const axios = require('axios');

const url = "https://api.lix-it.com/v1/li/messages?viewer_id=YOUR_VIEWER_ID&conversation_id=YOUR_CONVERSATION_ID";

    'Authorization': 'lixApiKey'
};

axios.get(url, { headers })
    .then(response => console.log(response.data))
```

## Send Message

Send a message to an existing LinkedIn conversation.

<Note variant="purple">
Uses 1 Standard Credit.
</Note>

### HTTP Request

`POST https://api.lix-it.com/v1/li/messages`

### URL Parameters

#### Required Parameters

Parameter | Description
--------- | -----------
viewer_id | The Lix viewer id of the account you would like to send the message as.

### Body Parameters

Parameter | Description
--------- | -----------
conversation_id **or** conversation_urn | The Lix conversation id or the full LinkedIn conversation URN. You must provide exactly one of these two parameters.
body | The message text to send. Maximum 8,000 characters.

<CodeGroup title="Send Message" tag="POST" label="/v1/li/messages">
```bash {{ title: 'Shell' }}
curl -X POST "https://api.lix-it.com/v1/li/messages?viewer_id=YOUR_VIEWER_ID" \
  -H "Authorization: lixApiKey" \
  -H "Content-Type: application/json" \
  -d '{
    "conversation_id": "YOUR_CONVERSATION_ID",
    "body": "Hey, we launched a new version of our product."
  }'
```

```python {{ title: 'Python' }}
import requests

url = "https://api.lix-it.com/v1/li/messages?viewer_id=YOUR_VIEWER_ID"

payload = {
    "conversation_id": "YOUR_CONVERSATION_ID",
    "body": "Hey, we launched a new version of our product."
}

headers = {
    'Authorization': 'lixApiKey',
    'Content-Type': 'application/json'
}

response = requests.post(url, headers=headers, json=payload)
print(response.json())
```

```go {{ title: 'Go' }}
package main

import (
    "bytes"
    "fmt"
    "io/ioutil"
    "net/http"
    "log"
)

func main() {
    payload := []byte(`{
        "conversation_id": "YOUR_CONVERSATION_ID",
        "body": "Hey, we launched a new version of our product."
    }`)

    req, err := http.NewRequest("POST", "https://api.lix-it.com/v1/li/messages?viewer_id=YOUR_VIEWER_ID", bytes.NewBuffer(payload))
    if err != nil {
        log.Fatal(err)
    }

    req.Header.Set("Authorization", "lixApiKey")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, err := client.Do(req)
    if err != nil {
        log.Fatal(err)
    }
    defer resp.Body.Close()

    body, err := ioutil.ReadAll(resp.Body)
    if err != nil {
        log.Fatal(err)
    }

    fmt.Println(string(body))
}
```

```javascript {{ title: 'Node.js' }}
const axios = require('axios');

const url = "https://api.lix-it.com/v1/li/messages?viewer_id=YOUR_VIEWER_ID";
```
